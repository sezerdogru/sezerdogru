# Hey, I'm Sezer 👋

I'm a **full-stack developer**: I build things end to end, from the React / Next.js / TypeScript frontend, to Node.js and PHP backends on PostgreSQL, to mobile apps and cloud deployment. Lately I've been spending my time on headless commerce, passkeys, and shipping small AI-powered products.

I recently finished my MSc in Computer Science in Hungary 🇭🇺 (with a semester at TU Wien 🇦🇹).

---

## 🔭 What I'm into right now

- 🤖 Building LLM-powered apps, playing with RAG chatbots and vision-language models (VLMs)
- 🔐 Passkeys / WebAuthn (I contributed some of it to Strivacity's open-source SDKs, see below)
- 🛍️ Headless e-commerce with Shopify Hydrogen, Next.js and GraphQL
- ☁️ Serverless stuff on AWS

## 🧪 Things I've made

- [**Pdf2portfolio.com**](https://pdf2portfolio.com): upload your PDF résumé, get a portfolio website. Uses an LLM under the hood.
- [**KaplanMakro.com**](https://kaplanmakro.com): a game automation tool, Python bot plus a Next.js dashboard.
- **MSc thesis**: an Android app for custom camera tuning profiles, plus a Next.js web app with AI image editing, running on AWS Lambda.
