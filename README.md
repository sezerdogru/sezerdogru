# Hey, I'm Sezer 👋

I build things for the web, mostly with **React, Next.js and TypeScript**. Lately I've been spending my time on headless commerce, passkeys, and shipping small AI-powered products.

I live in Bursa 🇹🇷, and I recently finished my MSc in Computer Science in Hungary 🇭🇺 (with a semester at TU Wien 🇦🇹).

---

## 🔭 What I'm into right now

- 🤖 Building LLM-powered apps and playing with RAG chatbots
- 🔐 Passkeys / WebAuthn (I contributed some of it to Strivacity's open-source SDKs, see below)
- 🛍️ Headless e-commerce with Shopify Hydrogen, Next.js and GraphQL
- ☁️ Serverless stuff on AWS

---

## 🧪 Things I've made

- [**Pdf2portfolio.com**](https://pdf2portfolio.com): upload your PDF résumé, get a portfolio website. Uses an LLM under the hood.
- [**KaplanMakro.com**](https://kaplanmakro.com): a game automation tool, Python bot plus a Next.js dashboard.
- **MSc thesis**: an Android app for custom camera tuning profiles, plus a Next.js web app with AI image editing, running on AWS Lambda.
- **TU Wien research project**: object detection in kitchen scenes with YOLOv8 and vision-language models.

## 🔐 Open-source: WebAuthn for Strivacity's SDKs

A few PRs I opened while interning at [Strivacity](https://github.com/Strivacity):

- [sdk-js #27](https://github.com/Strivacity/sdk-js/pull/27): WebAuthn types and example widgets for Next.js, React, Remix, Angular, Vue, Nuxt and Ionic (approved by maintainers, continued by the team in a follow-up PR)
- [sdk-mobile-kotlin-native #2](https://github.com/Strivacity/sdk-mobile-kotlin-native/pull/2): WebAuthn widget for the Kotlin SDK
- [demo-mobile-ios-native #1](https://github.com/Strivacity/demo-mobile-ios-native/pull/1): WebAuthn in the iOS demo app
